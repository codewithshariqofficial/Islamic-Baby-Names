## About

A **beautiful Islamic baby names collection** with meanings. Browse through a curated list of Islamic names for boys and girls, search by name, and filter by gender.

Built with **vanilla HTML, CSS, and JavaScript** -- clean and easy to use.

---

## Features

| Feature | Description |
|---------|-------------|
| Boy Names | Collection of Islamic boy names |
| Girl Names | Collection of Islamic girl names |
| Meanings | Each name has its meaning |
| Search | Search names by keyword |
| Filter | Filter by gender |
| Clean UI | Beautiful card layout |
| Responsive | Works on all devices |
| Fast Search | Instant search results |

---

## Tech Stack

```
HTML5  -->  Name Cards, Search and Filter UI
CSS3   -->  Clean Design, Grid Layout, Responsive
```
